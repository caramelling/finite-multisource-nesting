# Research data

This directory contains de-identified research inputs, archived computational results, bar- and part-level allocation records, representative links and figure source tables. The sole author has authorized public distribution of these records.

## Records and verification

The files retain the recorded scientific lengths, grades, sections, weights, seeds and computational outcomes; direct engineering identifiers have been replaced. File coverage and field definitions are described in `docs/COVERAGE.md` and `docs/DATA_DICTIONARY.md`. Run `python scripts/verify_release.py` from the repository root to independently check the archived allocations without launching a new optimization run.
