# 可复现统计重分析

[English](STATISTICAL_REANALYSIS.md) | **简体中文**

本次为基于既有计算结果、设置明确的新统计分析，不是找回或恢复原统计程序。全过程不运行套料优化；原始输入、既有方案、冻结计算模块和归档统计表保持原样。

## 复现方法

在研究包根目录安装`requirements-statistics.txt`，然后运行：

```bash
python scripts/reproduce_statistics.py --output outputs/statistics
python -m unittest discover -s tests -p test_statistics.py -v
```

既有重分析输出位于`data/results/reanalysis_20261108/`，命令可重新生成其中8个文件。`configs/statistical_reanalysis.json`固定全部设置；`provenance.json`记录输入、配置、实现的SHA-256及Python、NumPy、SciPy版本，不包含私人绝对路径。统计脚本不导入优化器。

## 统计单位与方法

- **主实验**：由100次既有S0–S4运行按相同的20个种子配对，比较S0–S1、S0–S2、S3–S4和S0–S4。差值为A减B，正值表示B采购较低。种子代表同一固定船舶问题的随机运行，不是20艘独立船舶。
- **数值归一化**：采购重量先按`0.000000001 t`表示为整数，再求差，采用十进制半偶舍入，消除浮点噪声，不改变论文报告的采购数量。标准定尺母材长度采用整数毫米；偶数个种子的中位数允许半毫米，排序时使用倍整数。
- **置信区间**：100,000次配对百分位bootstrap，95%区间，第2.5和97.5百分位数采用线性插值。主实验对完整种子行有放回抽样，各场景和指标共享索引；PCG64以`SeedSequence([20261108, 0])`初始化，regret消融使用`SeedSequence([20261108, 1])`。区间是逐项区间，不是经过多重校正的同时区间。
- **符号秩检验**：双侧，排序前删除零差，绝对差相同者取平均秩。原假设为差值分布关于零对称。对非零秩的全部符号组合建立精确条件分布，使用倍秩整数动态规划，完整处理并列秩；p值为较小含端点尾概率的两倍，最大取1。全零差集合定义p=1。
- **多重比较**：主实验四组重量比较和四组根数比较分别进行Holm校正；标准定尺开发验证与测试两个划分分别校正六组比较；regret消融为单项比较。所有比较均保留，不按显著性筛选。
- **标准定尺**：先按分段及方法汇总种子中位母材长度，再在20个开发验证分段和7个测试分段上比较。Friedman检验使用并列秩校正及自由度3的卡方参照。同船分段存在依赖，不能把该比较改称独立船舶验证。

## 与原归档的关系

主实验S3–S4结果仍为配对差中位数**0.037400 t**、逐项95%区间**0.029920–0.078540 t**、Holm校正**p=0.0000152587890625**，17对降低、2对相同、1对升高的记录不变。代表方案的2.500 m采购差来自既有分配方案，不是bootstrap估计。

regret-1对regret-2重分析**p=0.8050556182861328**，归档为**0.8194255828857422**；差值中位数、置信区间以及不显著的解释不变。2026年11月9日的原源码复核已确认原因：直接浮点相减使4组本应并列的绝对差被拆为不同秩。将整数归一化后的差值送入原精确检验函数，即可得到新的p值，正秩和由111.5变为112.0。`archive_comparison.csv`保留新旧结果，包含主实验重量、根数全部比较。区间显示末位的微小变化来自十进制舍入，不是套料结果变化。

本地独立核验采用SciPy穷举符号置换核验S3–S4和regret的精确p值，采用SciPy百分位bootstrap核验四组主实验重量区间。单元测试另含小样本独立穷举秩分布和输出确定性检查。

原源码复核已在统计来源和配对关系范围内完成：重现23个历史产物文件，核对100条主实验结果及2,070条标准定尺运行记录，并确认公开的8个冻结模块均与原工程中的归档快照一致。当前工作目录中有3个模块不同于冻结快照，发布包继续使用冻结版，未将工作目录代码冒充实验执行版本。详见[复核报告](ORIGINAL_STATISTICS_CROSSCHECK_zh.md)及`metadata/original_statistics_crosscheck.json`。论文继续采用设置明确的新重分析，不把历史参数静默替换成新参数，也不重新运行优化或自动上传网络。

## 输出字段

- `main_comparisons.csv`：四组比较的中位差、逐项区间、正负零差数、秩和、精确p值分子/分母及对应Holm校正值。重量效应与区间单位为t，根数效应与区间单位为根。
- `main_paired_differences.csv`：80条归一化配对记录，每组20条。
- `standard_block_medians.csv`和`standard_pairwise.csv`：分段方法汇总及各划分六组比较。
- `regret_ablation.csv`：20种子变体减完整方法的重量差，单位t。
- `archive_comparison.csv`：归档值、重分析值及新值减旧值。
- `statistics.json`和`provenance.json`：结构化结果、设置、版本、哈希。

方法参考SciPy的`wilcoxon`、`bootstrap`及NumPy的`SeedSequence`接口文档，具体计算以随包实现和固定依赖版本为准。
